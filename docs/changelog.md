## 未发布：1.0 产品完善工作

基于 0.1.1 开发中的产品能力，尚不是正式 1.0 发布声明。实现、验证和外部发行条件分别由[产品清单](product-plan.md)、[验证记录](verification.md)与[发行指南](releasing.md)记录。

- 将项目与工作区分开，增加默认 Git worktree 隔离、比较 / 应用 / 清理和共享目录执行保护，保留既有 native session 的 cwd。
- 增加持久化输入草稿、结构化引用、编辑缓冲区与视图恢复；加强原子保存、保存冲突、存储失败与进程中断恢复。
- 增加基线变更审阅、受指纹保护的选择撤销，以及明确执行、可取消并保存实际结果的检查任务。
- 完成暂存 / 未暂存分组审阅、提交预览、分支创建、历史、上游状态、fetch、仅快进 pull 和普通 push。
- 扩展项目信任与管理、会话置顶 / 归档 / 回收 / 搜索定位 / 导出、任务收件箱、多终端和输出引用。
- 增加文件快开 / 内容搜索 / CRUD、保存全部、外部编辑器、布局设置和键盘入口。
- 增加数据库迁移、长输出附件备份与恢复、有限脱敏诊断、长工具输出独立存储与按需读取，以及内部 / 签名候选构建和更新配置。
- 接入固定旧版基线的原生安装、升级与卸载保留数据检查。[CI run 41568623697](https://github.com/pspgbhu/coding-hub/actions/runs/41568623697) 的提交 `15bb76a` 已在 macOS x64 / arm64 分别通过源码 E2E 17 项、安装包 E2E 17 项和安装升级 13 项断言；同轮 Windows 单元测试失败，后续修复待新一轮原生 CI 验证。

当前边界：内置编辑为 2 MB UTF-8 文本；自动撤销需要完整文本快照，敏感配置、二进制和容量外文件除外；应用内备份需同时保留 SQLite 和配套输出附件，不包含项目源码、worktree 或 CLI 账号目录。生产签名、公证、更新源、Gatekeeper / SmartScreen、人工辅助技术验收，以及 Windows 原生安装升级仍需独立通过证据。
