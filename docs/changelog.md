# 变更记录

## 未发布：1.0 产品完善工作

基于 0.1.1 内部测试构建中的产品能力，尚不是正式 1.0 发布声明。实现、验证和外部发行条件分别由[产品清单](product-plan.md)、[验证记录](verification.md)与[发行指南](releasing.md)记录。

- 新建会话改为直接输入、首发创建；项目、按 Agent 分组的模型、原生思考强度与工作区使用就地选择菜单。各项目独立保存新草稿和模型偏好，首发支持去重与原子清稿。
- 将项目与工作区分开，支持可选 Git worktree 隔离、比较 / 应用 / 清理和共享目录执行保护；新会话默认使用本地共享目录，保留既有 native session 的 cwd。
- 增加持久化输入草稿、结构化引用、编辑缓冲区与视图恢复；加强原子保存、保存冲突、存储失败与进程中断恢复。
- 增加基线变更审阅、受指纹保护的选择撤销，以及明确执行、可取消并保存实际结果的检查任务。
- 完成暂存 / 未暂存分组审阅、提交预览、分支创建、历史、上游状态、fetch、仅快进 pull 和普通 push。
- 扩展项目信任与管理、会话置顶 / 归档 / 回收 / 搜索定位 / 导出、任务收件箱、多终端和输出引用。
- 增加文件快开 / 内容搜索 / CRUD、保存全部、外部编辑器、布局设置和键盘入口。
- 增加数据库迁移、长输出附件备份与恢复、有限脱敏诊断、长工具输出独立存储与按需读取，以及内部 / 签名候选构建和更新配置。
- 自动创建隔离 worktree 时临时禁用 Git hooks，避免间接运行项目脚本；手动 checkout、commit 的 hooks 继续生效，不修改用户 Git 配置。
- 按纯自用定位使用内部构建和手动更新；真实发行证书、公证及生产签名更新移为未来对外分发选项，不再作为自用前置条件。现有签名与更新校验保留。
- 按用户要求暂缓人工 VoiceOver / NVDA、物理 DPI / 系统缩放 / 多屏、固定专用硬件性能三项验收；保留未验收状态，不作为当前自用交付门槛。
- 接入固定旧版基线的原生安装、升级与卸载保留数据检查。[CI run 41667539505](https://github.com/pspgbhu/coding-hub/actions/runs/41667539505) 的[提交 `cc1d8db`](https://github.com/pspgbhu/coding-hub/commit/cc1d8db7cc0f1c7624ecbbb92d85cb86f1f23383) 已在 macOS x64 / arm64 分别通过 302 项单元测试（1 项跳过），原生 Windows x64 通过 295 项（8 项跳过）；三平台均通过源码 E2E 17 项、安装包 E2E 17 项和安装升级 13 项断言，包括 Windows 真实 NSIS 安装与卸载。当前 DMG / ZIP / EXE 已下载并核对实际文件摘要与清单，安装器与同轮报告一致。

当前边界：内置编辑为 2 MB UTF-8 文本；自动撤销需要完整文本快照，敏感配置、二进制和容量外文件除外；应用内备份需同时保留 SQLite 和配套输出附件，不包含项目源码、worktree 或 CLI 账号目录。未来公开分发的生产签名、公证、可用更新源与 Gatekeeper / SmartScreen 体验尚未验收；人工辅助技术、硬件多显示器与固定专用硬件性能验收已按用户要求暂缓，仍未验收。虚拟化 arm64 CI 不能替代物理 arm64 硬件验收。
