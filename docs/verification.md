# 验证记录

验证日期：2026-11-03。当前版本：0.1.1 内部测试包；不是正式 1.0 发行声明。
宿主：macOS x64，Darwin 25.5.0，Intel Core i7-1068NG7，8 逻辑核、32 GiB 内存。
构建使用 Node 24.18.0、pnpm 11.24.0、Electron 45.2.1；原生模块测试使用 Electron 内置 Node 24.22.1。

## 本轮产品补全

已实现并分别覆盖草稿与编辑缓冲区保存、独立 worktree、项目可信状态、结构化上下文、审批审计、逐轮变更审阅与安全撤销、可取消检查任务、完整 Git 交付、项目和会话管理、多终端、布局与快捷键、备份恢复、健康诊断、分页及长输出。逐项范围见[交付清单](product-plan.md)。

当前规则是：共享目录或同一 worktree 同时只执行一个 Agent 回合；独立 worktree 可以并行。旧原生会话的 cwd 保持不变。新 Git 仓库没有 HEAD 时使用共享目录；不会自动安装依赖、复制凭据或运行项目脚本。

## 数据与故障验收

- SQLite 写入成功后才允许 CLI 执行；磁盘失败暂停调度，积压事件按原协议顺序重试。原生 item ID、session ID、turn ID 和流式完成边界保留。
- 保存与撤销检查文件指纹、外部修改、路径 / symlink 边界、BOM / CRLF 与文件权限；Git 提交确认整个暂存区，拒绝隐含提交其他文件。
- 数据迁移、未来 schema 拒绝、完整性检查、SQLite / WAL / SHM 与配套输出附件恢复均有故障注入。恢复失败回滚原件；当前输出附件已损坏时先保存单独的损坏现场，再替换可验证备份。
- 原生取消失败保持占用。Runtime 丢失后，先按进程身份确认清理 CLI、PTY 与检查进程，再终结回合和检查任务；不自动重新发送。检查终态写盘失败保留内存状态，可重试落盘。
- 真正令 renderer 崩溃后，由生产恢复逻辑自动重载。已保存的草稿、未保存编辑内容恢复；同一 Runtime 中原 PTY、历史输出和输入继续可用。测试没有手动刷新页面来代替恢复逻辑。
- 原生 `app.quit()` 路径先冻结输入并等待最新草稿、Monaco 缓冲区和设置确认保存，然后停止原生回合、保存完整回合 review，最后关闭后台和数据库。测试覆盖立即退出时尚未到期的 150 / 250ms 自动保存；不将此表述为物理按键 Cmd+Q 测试。
- 会话导出覆盖全部历史及分页工具输出，使用临时文件和原子替换；拒绝覆盖数据库、备份、输出与进程所有权文件，也拒绝通过外部 symlink 别名绕过。诊断导出默认不含会话正文。

原生工具展示与诊断会过滤已知凭据格式，流式输出支持跨块凭据脱敏。用户主动输入的正文、源码、补丁和问答不会被任意改写；不能据此承诺用户数据永远不含敏感内容。详见[隐私与支持](privacy-and-support.md)。

## 性能与界面证据

[完整服务层报告](../coverage/benchmarks/performance-full.json)记录真实 SQLite、10,000 事件的会话、1,000 会话和 50,000 个真实文件，非内存模拟：

| 指标                       | 本机结果                                 | 边界                                                        |
| -------------------------- | ---------------------------------------- | ----------------------------------------------------------- |
| 100 条历史页读取 p95       | 0.91ms                                   | 服务层，不含 UI 绘制                                        |
| 中文历史搜索 p95           | 101.47ms                                 | 20 次本机样本                                               |
| 50,000 文件 quick-open p95 | 363.39ms                                 | 文件名匹配；真实空文件；冷初始化 1,766.83ms；不代表全文扫描 |
| 流式生产链路               | 2,000 个原始增量合并为 21 次 SQLite 写入 | EventBatcher → OutputStore → Store；突发输入，非网络节奏    |
| 工具长输出                 | 2,214,000 字节，68 页读取，完整哈希一致  | 历史预览 64 KiB；单项输出上限 32 MiB，触顶有提示            |

`Store.append` 单独逐条写入的对照同样保留在报告中；上述合并结果不能被描述为直接写入本身没有开销。数据构建、文件创建不计入操作耗时。本机负载会影响数字。

[真实 Electron 报告](../coverage/benchmarks/desktop-full.json)由完整进程重启、实际会话列表挂载、首次 100 条消息挂载及两帧绘制测量。最终数据随本轮 E2E 更新；本机阈值为启动 ≤5s、首屏历史 ≤1s。1,000 条侧栏只挂载可见行，按键可到达首尾；较早的搜索命中会定位到分页历史。

深浅主题、Monaco 实际文本绘制、面板伸缩、字体与缩进持久化、150% / 200% Electron zoom、三面板快捷键和命令面板均有自动化检查。截图位于 `coverage/visuals/`。zoom 是应用内缩放，不能替代真实高 DPI、多显示器与操作系统缩放。核心控件有名称、焦点路径和状态播报，尚未完成 VoiceOver / NVDA 人工验收。

## 内部安装包与升级

最终 macOS x64 DMG / ZIP 使用原生 electron-builder 构建，签名身份自动发现关闭，`--publish never`，没有对外发布。包内包含真实 SQLite、PTY、preload 和 CLI 控制层；packaged E2E 直接启动包内可执行文件。

`node scripts/macos-install-smoke.mjs` 将现有 0.1.0 与新 0.1.1 DMG 只读挂载，复制到私有临时 Applications 目录的同一个 `.app` 路径，依次启动旧版、替换新版、退出并重开：

- schema 1 → 2；项目、会话、中文事件与事件 ID、原生 session ID、历史 cwd 和主题保持。
- 新草稿、上下文与未保存编辑缓冲区重开后恢复；源代码文件未被未保存内容覆盖。
- 删除临时 `.app` 后，独立 userData 仍保留；断言后才清理测试目录。

[安装报告](../coverage/installation/macos-x64.json)记录两份 DMG 摘要、真实版本 / 架构 / appPath、各阶段断言与清理结果。最终重打包后再次执行，报告摘要须匹配实际文件。脚本不使用用户的 `/Applications` 或默认数据目录，也不使用真实 CLI / 模型账号。

此验证覆盖本机原生复制、替换与移除，不覆盖 Finder 鼠标拖动、Gatekeeper / quarantine、公证、生产签名、更新源下载、Windows NSIS 或 arm64 硬件。校验和保存在 `release/SHA256SUMS.txt`，摘要一致不等于发行者签名已验证。
